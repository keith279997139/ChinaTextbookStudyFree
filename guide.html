查找指南：三分钟定位你要的那本电子课本

电子课本找不到，九成不是平台没有，而是版本、册次、学科三个条件里有一个对不上。下面这套顺序能覆盖绝大多数情况。

一、先确认版本，别凭印象选

同一门课在不同地区用的可能是完全不同的教材。判断依据按可靠性排序：

  1. 翻开纸质课本扉页，看出版单位（人民教育出版社 / 北京师范大学出版社 / 江苏凤凰教育出版社……）。
  2. 看封面上是否印有「教育部审定 20XX」字样，年份决定内容版本。
  3. 问清楚是否统编教材：道德与法治、语文、历史三科为全国统一编写，其他学科仍按版本区分。
2024 年秋季起，依据 2022 年版课程标准修订的义务教育教材陆续投入使用，三科统编教材三年内覆盖所有年级。遇到「新教材 / 旧教材」并存的情况，以学校实际发放的那本为准。

二、再核对册次与模块

学段常见册次表述容易踩的坑
小学一年级上册 / 下册上册下册目录完全不同，按学期选
初中七年级上册 … 九年级下册「年级」不等于「册次」，五四学制地区另有分册
高中必修第一册、选择性必修第二册必修与选择性必修是两套书，不能混用
大学第 X 版、上 / 下册同名教材不同版次章节顺序差别很大

三、检索技巧

在国家中小学智慧教育平台

  • 进入「教材」或「电子教材」板块，按学段 → 学科 → 版本 → 年级册次逐级展开，不要一上来就用关键词搜整本书名。
  • 平台按教材章节组织课程资源，点开某一课可直接看同章节的微课、课件与作业，比在搜索框里翻更准。

在人教社电子教材页

  • 页面提供学段、学科、年级三个下拉筛选，先选学段再选学科，选项会随之收窄。
  • 若只记得书名片段，用浏览器自带页内查找（Ctrl+F / ⌘F）比平台搜索更快。

通用技巧

  • 把教材全名当作检索词，例如「义务教育教科书 数学 五年级上册」，命中率远高于「五年级数学」。
  • 找不到时退一步：先用本站 资源库 的搜索框确认哪个平台覆盖该版本，再进平台细找。

四、常见问题

平台上没有我要的那个版本怎么办？

官方电子教材并非全版本覆盖，尤其是地方版本与部分学科。可依次尝试：换到人教社电子教材页查 → 查该出版社官网是否有数字教材入口 → 咨询学校或当地教研部门。本站不提供、也不转载任何教材扫描件。

能下载 PDF 或打印吗？

多数官方平台是在线阅览，是否提供下载取决于平台自身设置与版权授权，请遵守页面提示。需要纸质书时，建议通过正规渠道购买。

可以用于教学或商用吗？

不可以。国家智慧教育平台的资源免费但不授权商业使用；人教社电子教材页明确标注「仅供个人学习使用，未经授权不得另做他用」。课堂集体使用、二次分发、剪辑上传都属于超出授权范围。

手机上看排版乱？

电子课本多为固定版式，手机竖屏阅读体验有限。建议横屏、或在平板 / 电脑上打开；部分平台提供专用客户端，适配更好。
