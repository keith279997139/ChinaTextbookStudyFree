About

关于本站

一个纯粹的导航索引：让找教材这件事少绕几个弯，同时不碰版权红线。

这是什么

ChinaTextbookStudyFree 是一个静态网页，收录中小学到大学阶段常见教材与学习资源的官方免费入口，提供按学段筛选与关键词检索，帮助使用者快速跳到对应平台。

本站只有 HTML、CSS 与 JavaScript，没有后端，不收集任何用户数据，也不设置账号体系。

收录原则

  • 只链官方或明确授权免费的来源：教育部主导的国家智慧教育平台系列、出版社自有电子教材页、高校与公益机构运营的开放课程和开放教材。
  • 不托管、不转载、不镜像任何教材文件：所有阅读行为发生在原平台，本站不提供 PDF 下载、网盘链接或扫描件。
  • 宁缺毋滥：无法确认授权状态的资源不收录，即便是流传很广的「教材合集」。

免责声明

本站所列资源的知识产权归各出版机构、平台运营方所有。本站仅提供超链接索引，不主张对上述内容的任何权利。

资源是否可访问、是否需要注册、是否提供下载，均以原平台页面为准；平台调整地址或下架内容时，本站可能短暂滞后，欢迎反馈。

请勿将本站收录的资源用于商业用途、二次分发或任何超出原平台授权范围的场景。

反馈与更正

链接失效、平台更名、分类建议，可在 GitHub Issues 提出；愿意直接改的话，欢迎提 Pull Request，资源清单位于 assets/resources.js，新增一条只需补一个对象。

技术说明

  • 纯静态站点，由 GitHub Pages 从 main 分支根目录发布。
  • 无第三方统计、无 Cookie、无外部字体请求，页面资源全部本地化。
  • 支持键盘操作：按 / 聚焦搜索框，Esc 清空。
